# Что видит сайт

Локальная страница, которая показывает, какие данные о вас доступны любому сайту:
IP и провайдер, часовой пояс, язык, устройство, экран, видеокарта, цифровой отпечаток,
куки и хранилища, состояние разрешений, HTTP-заголовки. Камера включается только по кнопке,
других запросов разрешений нет.

## Запуск

```
python3 server.py
```

- На этом компьютере: http://localhost:8080
- С телефона или другого компьютера в той же сети: https://<IP-компьютера>:8443
  (адрес печатается в консоли). Сертификат самоподписанный, поэтому браузер покажет
  предупреждение: «Подробнее» → «Перейти на сайт» (Safari: «Показать подробности» → «посетить этот веб-сайт»).
- По HTTP с другого устройства камера не работает, поэтому сервер сам перенаправляет на HTTPS.
- Если macOS спросит, разрешить ли входящие подключения для python3, нажмите «Разрешить».

Порты меняются так: `HTTP_PORT=8000 HTTPS_PORT=8444 python3 server.py`.
Остановить: Ctrl+C.

Сервер ничего не сохраняет. Он ставит демонстрационные куки (одна из них HttpOnly) и запрашивает
Client Hints, чтобы показать, что сайт может узнать без разрешения. Публичный IP и геолокация
по IP запрашиваются из браузера у сервиса ipwho.is.
